# Стенды проверки (tests/e2e)

Проверки «как у пользователя»: настоящее приложение (`src/index.js`) или его страницы, свой сервер
аккаунтов на запасном порту и **своя папка данных** — данные и лимиты пользователя не трогаются,
буфер обмена тоже (стенды не вызывают ничего, что пишет в него). Запуск — из корня репозитория:

```
node tests\e2e\app-e2e.js                         # Node 22+ (WebSocket), сам запускает Electron
node_modules\.bin\electron tests\e2e\login-test.js   # страницы со «стабами» вместо api — Electron
```

Перед первым запуском: `.venv\Scripts\python.exe tests\e2e\make-fixtures.py` (длинная запись, webm,
ссылка на собранный движок). Стендам, которым нужен **новый движок**, поднимите его рядом с запущенным
приложением (порт 8000 занят его движком):

```
cd auth-server
set WHISPER_PORT=8010& set WHISPER_MODEL=small& ..\.venv\Scripts\python.exe local_whisper.py
```
и запускайте стенд с `AUDIATOR_ENGINE_PORT=8010` (он уже прописан в long/limit/smooth/wav-e2e).
