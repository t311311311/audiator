# Стенды проверки (tests/e2e)

Проверки «как у пользователя»: настоящее приложение (`src/index.js`) или его страницы, свой сервер
аккаунтов на запасном порту и **своя папка данных** — данные и лимиты пользователя не трогаются,
буфер обмена тоже (стенды не вызывают ничего, что пишет в него). Запуск — из корня репозитория:

```
node tests\e2e\app-e2e.js                         # Node 22+ (WebSocket), сам запускает Electron
node_modules\.bin\electron tests\e2e\login-test.js   # страницы со «стабами» вместо api — Electron
```

Перед первым запуском: `.venv\Scripts\python.exe tests\e2e\make-fixtures.py` (длинная запись, webm,
ссылка на собранный движок). Стендам, которым нужен **новый движок**, поднимите его рядом с запущенным
приложением (порт 8000 занят его движком):

```
cd auth-server
set WHISPER_PORT=8010& set WHISPER_MODEL=small& ..\.venv\Scripts\python.exe local_whisper.py
```
и запускайте стенд с `AUDIATOR_ENGINE_PORT=8010` (он уже прописан в long/limit/smooth/wav-e2e).

| Стенд | Что проверяет | Как запускать |
|---|---|---|
| `app-launcher.js` | запускает `src/index.js` с папкой данных из `AUD_TEST_USERDATA` | используется другими |
| `app-e2e.js` | вход по коду (галочка правил), счётчик, «Написать нам» (4 темы, письмо с карточкой), язык окон из настроек, бар при открытых настройках, выход: история стёрта, окно входа, закрытие = выход | `node` |
| `account-e2e.js` | `src/account.js` против сервера: код, неверный код, 24 часа, офлайн-учёт, второй бесплатный на ПК, админ, шифрование сессии | `electron` |
| `history-e2e.js` | история между запусками: файл зашифрован, порядок, перевод, кнопки копирования, «нет речи» не хранится, выход стирает | `node` |
| `smooth-e2e.js` | плавный расчётный процент (короткая/длинная запись), выученная скорость ПК | `node` + движок 8010 |
| `limit-e2e.js` | лимит считается от начала записи | `node` + движок 8010 |
| `wav-e2e.js` | звук для движка сразу WAV 16 кГц (AudioWorklet), распознавание | `node` + движок 8010 |
| `limit-stop-ui.js` | запись сама останавливается, когда кончилось время; полоски уровня в кнопке (синтетический микрофон) | `electron` (`THEME=light`, `GAIN=0.6`) |
| `progress-ui.js` | тексты истории: «Ждёт очереди…», процент, готовый текст не затирается | `electron` |
| `login-test.js` | снимки: окно входа, счётчик, история, настройки (`SHOT_WHICH=login|main|settings`, `SHOT_LANG`, `SHOT_THEME`) | `electron` |
| `idle-cpu.js` | нагрузка процессов приложения в простое и с бочонками | `node` |
| `overlay-transparent.js` | бочонки поверх светлого/тёмного текста (`BG`, `FG`, `TAG`) | `electron` |
| `exe-final-smoke.js` | собранный «Audiator Engine.exe»: WAV-задание с процентами, перевод, отказ webm без PyAV | `node` |
| `terms-shot.js` | правила на языке `L` | `electron` |

Снимки (`*.png`) и `fixtures/` кроме `test-ru.wav` в git не идут (`.gitignore` здесь).

Известное: на машине разработчика (2026-10-04) `decodeAudioData` в Chromium ронял окно (0xC0000005) —
стенды его не используют.
