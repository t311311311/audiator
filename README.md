# <img src="src/icon.ico" width="32" height="32" align="top" alt="Audiator"> Audiator

**Audiator** — компактное приложение, которое живёт в системном трее и позволяет за секунды записать голос одной кнопкой, а затем онлайн выполнить транскрибацию (распознавание речи) и при необходимости перевести текст на другие языки.

Вы можете сохранять результаты в удобном виде: отдельно аудио, аудио вместе с текстом транскрибации, а также всю историю в текстовый файл — включая вариант перевода. Интерфейс настраивается под себя: выбор шрифта, переключение светлой/тёмной темы и регулировка прозрачности окна.

## 📋 Быстрый обзор

| Возможность | Описание |
|-------------|----------|
| 🎤 **Запись** | Запись аудио с микрофона одной кнопкой |
| 📝 **Транскрипция** | Автоматическое распознавание речи (Whisper API) |
| 🌐 **Перевод** | Перевод на 6 языков: английский, китайский, испанский, немецкий, французский, японский |
| 💾 **Сохранение** | Экспорт в WebM (аудио) и TXT (текст) |
| ⚙️ **Настройки** | Тема, шрифт, размер текста, прозрачность |
| 📋 **История** | Хранение всех транскрипций в окне приложения |

## 📥 Установка

1. Перейдите в раздел [Releases](https://github.com/t311311311/audiator/releases)
2. Скачайте последний установщик `Audiator Setup X.X.X.exe`
3. Запустите файл и следуйте инструкциям установщика
4. Приложение появится в системном трее (возле часов)

## 🚀 Использование

### Основная панель

| Кнопка | Действие |
|--------|----------|
| 🎤 | Начать запись |
| ⏹ | Остановить запись |
| 💾 | Сохранить аудио (WebM) |
| 💾+ | Сохранить аудио + текст |
| 📋 | Копировать текст в буфер |
| **Перевести** | Открыть панель перевода |

### Меню приложения (☰)

- **Настройки** — окно настроек приложения
- **Сохранить весь текст** — экспорт всей истории
- **Очистить историю** — удалить все записи
- **Выход** — полностью закрыть приложение

### Работа в трее

- **Клик по иконке** — показать/скрыть окно
- **Правый клик** — меню (Show App / Quit)

> ⚠️ Закрытие окна крестиком не завершает приложение — оно остаётся в трее.

## 📦 Разработка

```bash
# Клонирование репозитория
git clone https://github.com/t311311311/audiator.git
cd audiator

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка дистрибутива
npm run dist

# Обновление версии
npm run version:bump
```
