# <img width="57" height="88" alt="image" src="https://github.com/user-attachments/assets/7873ed08-3b72-4ceb-9243-9dd8f7dc2c62" /> Audiator


Audiator — компактное трей-приложение, которое живёт в системном трее и позволяет за секунды записать голос одной кнопкой, а затем онлайн выполнить транскрибацию (распознавание речи) и при необходимости перевести текст на другие языки.
Можно сохранять результаты в удобном виде: отдельно аудио, аудио вместе с текстом транскрибации, а также всю историю в текстовый файл — включая вариант перевода. Интерфейс настраивается под себя: выбор шрифта, переключение светлой/тёмной темы и регулировка прозрачности окна.

## Возможности

- 🎤 **Запись голоса** — запись аудио через микрофон
- 📝 **Транскрипция** — автоматическое распознавание речи (Whisper API)
- 🌐 **Перевод** — перевод текста на различные языки
- 💾 **Сохранение** — экспорт аудио (WebM) и текста (TXT)
- ⚙️ **Настройки** — тема, шрифт, прозрачность окна
- 📋 **История** — сохранение истории транскрипций

## Установка

1. Скачайте установщик из раздела [Releases](https://github.com/USERNAME/REPO/releases)
2. Запустите `Audiator Setup X.X.X.exe`
3. Следуйте инструкциям установщика

## Использование

| Кнопка | Действие |
|--------|----------|
| 🎤 | Начать запись |
| ⏹ | Остановить запись |
| 💾 | Сохранить аудио |
| 💾+ | Сохранить аудио + текст |
| 📋 | Копировать текст |
| Перевести | Перевести текст |

### Горячие клавиши

- Приложение сворачивается в трей при закрытии окна
- Клик по иконке в трее показывает/скрывает окно

## Настройки

- **Тема** — тёмная / светлая
- **Шрифт** — выбор шрифта отображения
- **Размер шрифта** — 10–24 px
- **Прозрачность** — 20–100%

## Требования

- Windows 10/11 (x64)
- Доступ к интернету (для транскрипции и перевода)

## Технологии

- [Electron](https://www.electronjs.org/) — кроссплатформенная оболочка
- [electron-builder](https://www.electron.build/) — сборка установщиков
- [electron-store](https://github.com/sindresorhus/electron-store) — хранение настроек
