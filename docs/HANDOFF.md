## Суть проекта в трёх строках

Трей-приложение на Electron: Ctrl+Space → говоришь → faster-whisper расшифровывает → текст уже
в буфере, «Готово! Ctrl+V» на плавающем баре → вставляешь куда угодно. Плюс перевод текста.
Сейчас это **личный инструмент пользователя**: весь бэкенд крутится **локально** на его ПК
(сервер HOSTKEY не продлён), платежи выключены. Коммерческий план — эпики AUD-1…6 в Jira.

Выбранный путь (2026-09-14): **«пока личный инструмент — дизайн, тесты, закрытие дыры, свежий установщик»**.

## Плавный процент распознавания (ветка `feat/smooth-progress`, 2026-10-05)

Движок сообщает ход только после каждого 30-секундного куска — короткая запись стояла на «0%» и казалась
зависшей. Теперь главный процесс раз в секунду считает оценку: прошедшее время / (длина записи × скорость
этого ПК для этой модели), не больше 95 %, пока текст не готов; настоящий процент движка берётся, когда он
больше; только вперёд; 0 % не показывается; перерисовка только при смене цифры. Скорость (секунд работы на
секунду речи) запоминается по каждой модели (`asrSpeed` в настройках, скользящее среднее, по записям от 5 с);
до первого замера — 0,35 / 0,8 / 2,0 (base / small / large-v3-turbo). На ноутбуке пользователя от батареи
small ≈ 0,7. Нагрузка — одна строка раз в секунду, только пока идёт распознавание.

## Логи сервера (ветка `feat/server-logs`, 2026-10-04)
