## Суть проекта в трёх строках

Трей-приложение на Electron: Ctrl+Space → говоришь → faster-whisper расшифровывает → текст уже
в буфере, «Готово! Ctrl+V» на плавающем баре → вставляешь куда угодно. Плюс перевод текста.
Сейчас это **личный инструмент пользователя**: весь бэкенд крутится **локально** на его ПК
(сервер HOSTKEY не продлён), платежи выключены. Коммерческий план — эпики AUD-1…6 в Jira.

Выбранный путь (2026-09-14): **«пока личный инструмент — дизайн, тесты, закрытие дыры, свежий установщик»**.

## Сессия 2026-09-25: кнопка записи и бар записи (ветка `fix/recording-ui`)

Пользователь нашёл и принял руками:
1. Кнопка записи меняла ширину при нажатии (стоп 59px vs запись 48px) → ряд прыгал, «Перевести» → «Переве…».
   Теперь все кнопки-значки 50×43, «Перевести» берёт остаток (130px) во всех языках.
2. Бар записи не появлялся, если окно просто перекрыто другим приложением (и при записи с кнопки, и после
   Ctrl+Space → клик по бару → уход в другое приложение). Причина: `isVisible()` true у перекрытого окна.
   Теперь `mainInView()` = показано + не свёрнуто + фокус у нашего окна; синхронизация по
   `browser-window-focus/blur` с задержкой 100 мс (иначе бар мигает при переходе главное → настройки).
3. Бар скрыт от демонстрации и записи экрана (`setContentProtection`, WDA_EXCLUDEFROMCAPTURE) — тумблер
   в настройках не нужен. Проверено: affinity 0x11, на снимке экрана бара нет. Минус: его нет и на своих скриншотах.
4. Кнопка записи — микрофон с бара: в покое статичный, при записи плавно «дышит» (1.4 с, 1↔0.45).
   Отвергнуты: мини-эквалайзер в кнопке, мигающая красная точка.
5. Подсказки «Запись (Ctrl+Space)» / «Стоп (Ctrl+Space)» на en/ru/zh.
6. Ctrl+Space больше не прячет окно — только переключает запись.
