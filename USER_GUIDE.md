# Audiator — Руководство пользователя

## 📖 О приложении

**Audiator** — компактное приложение, которое живёт в системном трее и позволяет за секунды записать голос одной кнопкой, а затем онлайн выполнить транскрибацию (распознавание речи) и при необходимости перевести текст на другие языки.

Вы можете сохранять результаты в удобном виде: отдельно аудио, аудио вместе с текстом транскрибации, а также всю историю в текстовый файл — включая вариант перевода. Интерфейс настраивается под себя: выбор шрифта, переключение светлой/тёмной темы и регулировка прозрачности окна.

---

## 🚀 Быстрый старт

### После установки

1. Запустите **Audiator** из меню «Пуск» или с ярлыка на рабочем столе
2. Приложение появится в системном трее (возле часов)
3. Кликните по иконке в трее, чтобы открыть окно приложения

## 📝 Пошаговая инструкция

### 1. Запись аудио

1. Нажмите кнопку **🎤 Запись**
2. Говорите в микрофон
3. Нажмите **⏹ Стоп** для завершения записи
4. Начнётся автоматическая транскрипция (распознавание речи)
5. Через несколько секунд появится текст

> ⏱ **Время обработки:** зависит от длины записи и скорости интернета

### 2. Просмотр истории

- Все записи сохраняются в истории внутри приложения
- Каждая запись отображается с датой и временем
- История очищается при закрытии приложения (если не сохранена)

### 3. Сохранение результатов

#### Сохранить только аудио:
1. После транскрипции нажмите **💾 Сохранить аудио**
2. Выберите место для файла
3. Файл сохранится в формате `.webm`

#### Сохранить аудио + текст:
1. Нажмите **💾+ Сохранить аудио + текст**
2. Выберите место для сохранения
3. Будут созданы два файла:
   - `ad_HHMMSS_DDMMYY.webm` — аудио
   - `tr_HHMMSS_DDMMYY.txt` — текст

#### Сохранить весь текст истории:
1. Откройте меню **☰** (в левом верхнем углу)
2. Выберите **«Сохранить весь текст»**
3. Весь текст истории сохранится в один файл

### 4. Копирование текста

#### Копировать последнюю запись:
1. Нажмите **📋 Копировать** (без выделения текста)
2. В буфер скопируется последняя запись (оригинал + перевод)

#### Копировать часть текста:
1. Выделите нужный текст мышью
2. Нажмите **📋 Копировать**
3. В буфер скопируется выделенный фрагмент

### 5. Перевод текста

1. После транскрипции нажмите кнопку **«Перевести»**
2. Внизу появится панель выбора языка
3. Выберите целевой язык:
   - 🇬🇧 English
   - 🇨🇳 Chinese
   - 🇪🇸 Spanish
   - 🇩🇪 German
   - 🇫🇷 French
   - 🇯🇵 Japanese
4. Нажмите **Go**
5. Перевод появится под оригиналом (выделен цветом)

## ⚙️ Настройки

Откройте меню **☰** → **«Настройки»**

### Тема оформления

| Тема | Описание |
|------|----------|
| 🌙 **Тёмная** | Стандартная тема (тёмный фон, светлый текст) |
| ☀️ **Светлая** | Светлый фон, тёмный текст |

### Шрифт

Доступные шрифты:
- **Arial** (по умолчанию)
- **Verdana**
- **Courier New** (моноширинный)
- **Times New Roman**
- **System UI** (системный шрифт)

### Размер шрифта

- Диапазон: **10–24 px**
- Изменяется ползунком
- Применяется к тексту транскрипций

### Прозрачность окна

- Диапазон: **20–100%**
- 100% — полностью непрозрачное окно
- 20% — почти прозрачное
- Изменение применяется в реальном времени

### Сохранение настроек

- **Сохранить** — применить и закрыть окно настроек
- **Отмена** — закрыть без сохранения изменений
- Настройки сохраняются между сеансами

> 💡 **Совет:** Нажмите <kbd>Esc</kbd> для быстрого закрытия окна настроек без сохранения.

## 🔧 Технические детали

### Требования к микрофону

- **macOS:** При первом запуске потребуется дать разрешение на доступ к микрофону
- **Windows 10/11:** Может потребоваться включить доступ для классических приложений в параметрах конфиденциальности
- Проверьте, что микрофон выбран устройством записи по умолчанию

### Требования к подключению

- **Транскрипция:** требуется интернет (Whisper API)
- **Перевод:** требуется интернет (сервис перевода)
- **Сохранение файлов:** работает офлайн

### Форматы файлов

| Тип | Формат | Описание |
|-----|--------|----------|
| Аудио | `.webm` | Современный аудиоформат с хорошим сжатием |
| Текст | `.txt` | Обычный текст в кодировке UTF-8 |

### Именование файлов

Файлы сохраняются с автоматическим именованием:
- `ad_HHMMSS_DDMMYY.webm` — аудио (ad = audio)
- `tr_HHMMSS_DDMMYY.txt` — текст (tr = transcription)
- `history_HHMMSS_DDMMYY.txt` — вся история

Где:
- `HHMMSS` — время (часы, минуты, секунды)
- `DDMMYY` — дата (день, месяц, год)

> ⚠️ **Примечание:** Формат даты `DDMMYY` может быть неудобен для сортировки файлов в проводнике. Для автоматической сортировки по имени рекомендуется переименовывать файлы в формат `YYYYMMDD_HHMMSS`.

## ❓ Часто задаваемые вопросы

### Где хранятся мои записи?

По умолчанию приложение не сохраняет файлы автоматически. Используйте кнопки **💾** для явного сохранения.

### Как очистить историю?

Меню **☰** → **«Очистить историю»** → подтвердить действие.

### Можно ли изменить сервер транскрипции?

В текущей версии сервер задан в коде приложения (`src/index.html`). Для изменения требуется редактирование исходного кода.

> 🔧 **Планы на будущее:** В следующих версиях параметр сервера будет вынесен в окно настроек или конфигурационный файл.

### Приложение не записывает звук

Проверьте:
1. Подключён ли микрофон
2. Выбран ли микрофон устройством записи по умолчанию
3. Есть ли у приложения доступ к микрофону (настройки Windows/macOS)

### Транскрипция не работает

Возможные причины:
- Нет подключения к интернету
- Сервер транскрипции недоступен
- Ошибка формата аудио (проверьте консоль разработчика)

### Как полностью выйти из приложения?

Меню **☰** → **«Выход»** или правый клик по иконке в трее → **Quit**.

> ⚠️ **Важно:** Закрытие окна крестиком не завершает работу приложения — оно продолжает работать в трее.

- Говорите чётко и недалеко от микрофона

- Периодически очищайте историю в приложении

- **Клик по иконке в трее** — быстро показать/скрыть окно
- **Выделение текста** → **📋** — копировать только нужное
- **<kbd>Esc</kbd>** в окне настроек — закрыть без сохранения
